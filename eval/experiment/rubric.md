# Answer rubric (0–3)

Score each spoken answer against the `answer_key` in `questions.csv`.

| score | meaning |
|---|---|
| 3 | Correct and complete: the key fact or number, stated without error |
| 2 | Mostly correct: the key point is there, a detail is missing or vague |
| 1 | Partly correct: related but misses the key fact, or a number is wrong |
| 0 | No answer, wrong answer, or "I don't know" |

Answer start time: from the end of the question audio to the first word of the answer
(not filler like "um"), measured from the session recording.

Two raters score independently where possible; report the mean.
